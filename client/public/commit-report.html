2. Project summary

RideRent is a MERN-stack bike rental marketplace. Owners (providers) list bikes, renters book them, and an admin oversees the platform.

  • Roles: user (renter), provider (bike owner, needs admin approval), admin.
  • Booking flow: request, provider approval, renter/owner chat, hand-over and return marked by the owner.
  • Money: the platform keeps a 10% commission on each booking.
  • Trust & safety: CNIC (KYC) verification reviewed by admin; images are stored privately.
  • Support: AI customer support chat (Google Gemini) and a Contact/support inbox for admins.
