RideRent

Project overview

RideRent is a website where people in Pakistan can rent a motorbike for a day or more, and bike owners can earn money by listing their bikes. This page explains the project without any code.

The problem and the solution

Problem

Renting a bike usually means visiting shops, calling around and paying cash without knowing prices or availability in advance. Bike owners with idle bikes have no simple way to rent them out safely.

Solution

One online marketplace: renters search bikes by city, price and brand, see the total cost, and request a booking for their dates. Owners list bikes after being verified by an administrator.

Who uses it

Renter (User)

Someone who needs a bike.

  • Browse and filter bikes
  • See price for chosen dates
  • Request, track and cancel bookings
  • Review bikes they rented
  • Get help from support chat

Bike Provider

A bike owner who rents out bikes.

  • Signs up and waits for approval
  • Adds, edits and pauses bikes
  • Accepts or rejects booking requests
  • Sees earnings (90% of each rental)

Administrator

The platform team.

  • Approves or removes providers
  • Manages users and bike listings
  • Sees bookings, revenue and the 10% platform earnings
  • Answers support messages

How it works

  1. Browse. Open “Browse Bikes” and filter by city, maximum daily rent and brand.
  2. Choose. Open a bike to see its photo, location and daily price.
  3. Pick dates. Select pick-up and drop-off dates; the total price is calculated instantly (minimum one day).
  4. Request. Log in or create an account, then “Request to Book”. The system stops double-bookings of the same bike.
  5. Wait for the owner. The request shows as Pending until the bike owner accepts or rejects it.
  6. Meet safely. Once accepted, both see each other’s phone number and the shop address and can chat. The customer goes to the shop with their original CNIC and licence and checks the bike; the owner then presses “Hand over”, which starts the ride.
  7. Ride and review. Approved bookings appear in “My Rental History”; future ones can be cancelled, and the renter can review the bike.
  1. Sign up as a provider using “Become a Provider”.
  2. Wait for approval. The admin checks the provider’s CNIC and shop details before the account is approved.
  3. Add bikes with name, brand, city, daily rent, description and a photo; edit them or switch them off when not available.
  4. Accept or reject each booking request.
  5. Track earnings. RideRent keeps 10%; the provider earns 90% of every approved booking.
  1. Verify accounts by checking each customer’s and provider’s CNIC, then approve or reject with a reason.
  2. Monitor totals of users, providers, bikes and bookings on the dashboard.
  3. Moderate by removing inappropriate bikes or accounts.
  4. Audit every booking and see total revenue and platform earnings.
  5. Support customers by answering messages sent from the Contact page.

Customer support: every public page has an AI support chat that answers questions about bikes, prices and the user’s own bookings, and a Contact page for questions that need a person.

Technology, in plain words

Website (front end)

What people see and click, built with React. Hosted on Vercel.

Server (back end)

The “brain” that checks logins, saves bookings and enforces rules, built with Node.js / Express. Hosted on Render.

Database

Where users, bikes and bookings are stored, using MongoDB, hosted on MongoDB Atlas.

AI customer support

Uses Google’s latest Gemini model, called from the server so the private key stays secret.

Together, MongoDB + Express + React + Node.js are known as the MERN stack.

Status & roadmap

Current status: all core features work when the project is run on the developer’s computer. The public website is online, but its server and database are not hosted yet, so the live site does not show bikes. Hosting the server is the next step.
  1. Next: host the server and database online so the live site works end to end.
  2. Then: email notifications and searching bikes by free dates.
  3. Future: online payments, mobile app, and a car rental module.

Glossary

Provider
A bike owner who lists bikes for rent.
Approval
An admin check before a provider can list bikes.
Booking
A request to rent one bike between two dates; pending until the owner accepts it.
Commission
The 10% share of each approved booking kept by RideRent.
Dashboard
A personal control page; each role has its own.
PKR / Rs.
Pakistani Rupees; all prices are per day.
Front end / Back end
The visible website / the server that stores data and applies rules.
